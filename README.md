# OpenCNC Fab
Repo for documents, designs, and material related to the OpenCNC Fab project.
The core goal? To make a DIY CNC that anyone should be able to build, which possesses a base level of automation and is easy to build upon.

Aiming to feature : 
* A simple ATC that avoids using expensive pneumatics and such
* Motorized part clamps and door to facilitate later automation
* Sound dampening
* A modern and complete user control panel
* A rigid motion frame capable of sustaining aluminium cutting forces
